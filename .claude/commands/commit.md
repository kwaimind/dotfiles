write a git commit message for the currently staged files using the conventional commits style. commit the files when you are done.

- Always use conventional commits format: `type: description`
- Valid types: feat, fix, docs, style, refactor, perf, test, build, ci, chore, revert
- Examples:
  - feat: add dark mode toggle
  - fix: handle expired tokens correctly
  - docs: update API documentation
- When creating commits:
  - Use imperative mood ("add" not "added")
  - Keep title under 72 characters
  - No period at end of title
  - No AI attribution
- Git author/email/signing is configured globally - never set these locally per-repo
